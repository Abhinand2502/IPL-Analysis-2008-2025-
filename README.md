# 🏏 IPL Analysis Dashboard (2008–2025)

![Dashboard](ipl_Dashboard.png)
## 📌 Overview
The IPL Analysis Dashboard is an interactive Power BI project that provides comprehensive insights into the Indian Premier League (IPL) from 2008 to 2025. The dashboard enables users to explore team performances, championship records, player achievements, and season statistics through dynamic visualizations and filters.

## 🚀 Features
- Season-wise IPL analysis (2008–2025)
- Champion and Runner-up tracking
- Interactive Points Table
- Orange Cap & Purple Cap winners
- Most Fours and Most Sixes analysis
- Team performance insights
- Venue statistics
- Dynamic filtering and drill-down capabilities
- IPL-themed dashboard design

## 📊 Key Metrics
- Total Teams
- Total Matches
- Total Fours
- Total Sixes
- Centuries
- Half-Centuries
- Venues
- Team Rankings
- Player Awards

## 🛠️ Tools & Technologies
- Power BI
- DAX
- Power Query
- Data Modeling
- Data Visualization
